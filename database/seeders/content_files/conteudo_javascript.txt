<p>O JavaScript tem uma característica fundamental: ele é <strong>"Single-threaded"</strong>. Isso significa que ele só consegue fazer uma coisa de cada vez. Imagine uma fila única no caixa do supermercado: se o cliente da frente demorar, todos atrás ficam parados.</p>

<p>No desenvolvimento web, isso é um problema. Se o seu código tiver que buscar dados no servidor (o que pode levar segundos) e o JS parar para esperar, a tela do usuário trava. O botão não clica, o scroll não funciona. Para resolver isso, usamos o <strong>Asincronismo</strong>.</p>

<h2>A Evolução da Sintaxe</h2>
<p>A forma como lidamos com tarefas demoradas no JS mudou muito ao longo dos anos para tornar o código mais legível.</p>

<h3>1. O Passado: Callbacks</h3>
<p>Antigamente, passávamos uma função para ser executada "depois que o processo terminasse". O problema é que, se precisássemos fazer várias coisas em sequência, criávamos uma estrutura aninhada conhecida como <strong>"Callback Hell"</strong> (ou Pirâmide da Perdição), que tornava o código impossível de ler e dar manutenção.</p>

<h3>2. O Meio-Termo: Promises (.then)</h3>
<p>As Promises chegaram para organizar a casa. Elas representam um valor que pode estar disponível agora, no futuro ou nunca. Usamos o <code>.then()</code> para encadear ações de forma linear.</p>

<h3>3. O Presente: Async / Await</h3>
<p>Introduzido nas versões modernas do ECMAScript, o <code>async/await</code> é o padrão atual de mercado. É importante entender que ele é um <strong>"Açúcar Sintático"</strong> (Syntactic Sugar) sobre as Promises. Por baixo dos panos, ele funciona igual, mas para quem lê, parece código síncrono comum.</p>



<h2>Comparação Prática</h2>
<p>Veja como a legibilidade melhora ao buscar dados de uma API:</p>

<p><strong>Com Promises (.then):</strong></p>
<pre><code>
function buscarDados() {
  fetch('https://api.exemplo.com/usuarios')
    .then(response => response.json())
    .then(data => {
      console.log(data);
    })
    .catch(erro => {
      console.error("Deu ruim:", erro);
    });
}
</code></pre>

<p><strong>Com Async/Await (Moderno):</strong></p>
<pre><code>
async function buscarDados() {
  try {
    // O código "espera" aqui sem travar a tela
    const response = await fetch('https://api.exemplo.com/usuarios');
    const data = await response.json();
    
    console.log(data);
  } catch (erro) {
    console.error("Deu ruim:", erro);
  }
}
</code></pre>

<p>Note o uso do bloco <code>try/catch</code> no segundo exemplo. Como o código parece síncrono, usamos a estrutura clássica de tratamento de erros para capturar falhas na requisição.</p>
